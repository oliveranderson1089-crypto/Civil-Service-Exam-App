# 公考助手 · Civil-Service-Exam-App

一个公务员考试备考工作台：**网页 + 安卓 APK + 电脑桌面版（Linux .deb / Windows）**，多用户、可远程访问、可离线使用（PWA）。

从「成语词语积累」起步，现在覆盖**历年真题、行测专项练、申论批改与成文、每日时政、常识与理论积累、错题本与遗忘曲线复习、笔记资料管理**，并带微信推送。

## 界面

**常驻导航**：手机是底部标签栏、电脑是左侧导航栏，五个标签 **今日 / 练 / 积累 / 库 / 我的**
（两者是同一份路由表的两个形态，出哪个只由屏幕宽度决定）。

首页是**今日仪表盘**——今日进度、一个主行动按钮、待办、今日更新、上次练习；
不是功能目录。分组维度是「动作」而不是「学科」：学科降级成标签页里的横向 chip，
横向切学科、纵向分动作。**「练」里选中一个板块 = 把板块页整页内联**，
原来 `首页→行测→言语理解→专项练` 四层，现在两层到位。

电脑端是三栏工作台：浅色工具栏（全局搜索 `Ctrl K` + 考试倒计时）、左侧两级导航（带待办角标）、
中间内容 + 面包屑、右侧常驻面板。做题页右栏可切 **答题卡 / AI 助手 / 草稿纸 / 笔记**——
答题卡能跳题、报用时与均速（模考模式只报答没答、不透出对错），「本题相关」告诉你这个考点
近 30 天练得怎么样；资料分析的材料单独占左栏，和题干并排。配 A–D / J·K / Enter 键盘操作。→ 细节见 [docs/README-full.md · 界面结构](docs/README-full.md#界面结构常驻导航--今日仪表盘)

**「库」和「我的」不再是目录条**：库 = 七个图标格（一屏摆得下全部容器，AI 产出跟小记云盘并列，不藏在助手里面）+ **最近打开**（不用先想东西存在哪），
我的 = 本周完成度环 + 一行一件的紧凑清单。两页各一个聚合接口，接口挂了照样能点——那些格子本来就是纯导航。

**AI 助手与聊天是两块重做过的屏幕**：AI 助手把首页 / 项目 / 项目详情 / 会话四个视图并成一栏
（手机半屏停靠、电脑进右栏，同一份组件两种外壳）；聊天电脑端是三栏，第三栏常驻信息栏
（成员、公告、共享文件、图片、置顶、免打扰）。两块共用同一份滚动契约（`static/js/convo.js`）——
只有你已经贴着底部时才自动跟，往回翻历史不会被新消息拽走。
**登录 / 注册 / 找回三页**的底色也跟着一天的时刻走（和启动屏、应用图标共用那副六锚点色表）。

**宽屏再多一栏「随手栏」**（≥1360）：填的是 1920 宽下内容列右边空着的 296px，
放待办 / 今日更新 / 最近打开 —— 数据全借首页和库页已经拉过的那两份，**不加接口**；
它一出现，首页中间那两段就撤走，不并排显示两遍。左栏五组**只展开一组**
（全铺开 20+ 项，1440 高的窗口进来就得滚），收起的组把组内角标冒到组头上。
内容列在 ≥1100 改**卡片网格**：940 的单列里一条列表行 888px 宽，标题在最左、成绩在最右，
中间七百多像素空白，改成 280 一格后同样高度从装九条到装二十四条。
→ [docs/README-full.md · 界面评审后的一轮打磨](docs/README-full.md#界面评审后的一轮打磨看得清--点得到--第三栏)

**外观里还有两个小开关**：图标风格（**线描 / 彩色 emoji**，默认线描 —— 以前想要一套统一的
单色图标就得连配色一起换）、底色跟着一天的时刻走（幅度极小，只动页面底和卡片底；
开了美术主题或处在夜间时不生效，也可以直接关掉）。

**主题风格**（账户 › 外观，默认不开）：**18 套**可选的美术方向，**手机和电脑各 9 套**
（手机是竖构图大色块、电脑是横构图细边框，两端各列各的）。
文房路子：**宣纸与印 / 天光琉璃 / 墨山 / 节气色**（手机）、**青瓷 / 卷宗 / 夜航 / 白台**（电脑）；
插画路子：**御前手账 / 女巫茶会 / 像素蜜桃 / 炸物猫铺 / 家庭菜园**（两端各一版，共用一条上色通道）。
选中之后**整个应用**的图标（全部功能九宫格、板块页、库的图标格、标签栏）、卡片材质、壁纸和**启动页**一起换，
并且**跟着一天的时刻连续渐变**（和应用图标共用同一副六锚点色表）。
可以只开配色不跟时刻，也可以完全不开、保持现在的样子。→ [docs/README-full.md · 主题风格](docs/README-full.md#主题风格18-套美术方向跟着一天的时刻渐变)

## 功能一览

### 行测

| 模块 | 一句话 |
|---|---|
| **历年真题** | 国考 2000–2026 + 四川 2007–2025 原卷，去重后 7606 道（7008 道可直接练）。智能刷 / 按题型刷（46 个题型）/ 整卷真题（**背题**：做一题就揭晓答案解析／**模考**：交卷才判分、走总倒计时）；每次作答独立留痕，错过的题到期自动排最前 |
| **⚡ 专项练** | 六大板块按题型刷，三档难度、按题型限时、薄弱题型排最前。资料分析 / 数量关系 / 图形推理**程序化出题**（答案由构造保证），其余 AI 出题 + 题库缓存。**做过的题不再重复发**——库存满 ≠ 有题做，补库按「你还剩多少没做过的」算，夜里优先补今天新学的知识点 |
| **基础知识点** | 两套机构讲义并行：**系统精讲**（章/节目录 + 例题解析）与**三色速记**（原书红蓝绿三色还原），外加**考点对照**——同一考点下先看详解、再看速记。讲义 PDF 由 `ingest_basics.py` 解析成考点树，公式和图形推理的图点开看**原书那一页**；学完就近练该考点的真题 |
| **每日巩固测试** | 按当天学的内容出一份小测，五个板块按配额组卷，背题 / 测试两种模式 |
| **常识 · 理论 · 时政** | 35 个专题 555 条常识考点、268 个理论考点、每日 3 次时政爬取 + AI 三行式解读、时政要文库、创新理论词典 316 条 |
| **成语词语 / 常考** | 高频成语 894 条（按真题考频排序、可看典故）、实词搭配、上位词、高频古诗文与提法，外加**每日古诗积累**（今日复习里当天新出的诗自动按天归档，回看背过哪些） |
| **每日新闻视频** | 抓央视网 / 川观 / B 站官方号，AI 按**公考价值**筛一遍并说清为什么值得看 |

### 申论

| 模块 | 一句话 |
|---|---|
| **真题批改** | 上传真题（PDF/Word/图片，扫描件自动 OCR）→ 自动拆题 → 逐题作答 → AI 按采分点逐点批改。两种做题模式可切：**模考**（直接写，还原考场）/ **练习**（先在材料上找点、判完再写）；采分点**预先标好存库**，同一份答案两次批改分数不飘，还能指出漏的点在材料第几句 |
| **范文推荐** | 按热门话题命制的仿真卷，材料严格按真题字数规格，每题配完整参考答案 |
| **成文** | 把积累的素材真正写成一篇大作文：每日成文 / 综合应用 / 14 个文种的应用文。**提纲归提纲、全文归全文**——每条论点在正文里落在哪一段都指得出来，正文换了说法就并排显示当「另一种写作思路」，不回头改写正文；用了哪些素材也逐条回正文核对过 |
| **小题训练** | 归纳概括 / 综合分析 / 提出对策 / 贯彻执行，拆成「只找不写」和「照着找到的点写」两步练。采分点**逐块扫全材料**标定（防止全挤在开头）+ 参考答案由采分点拼装；勾中「相关但没独立成点」的句子判**沾边**，不再误判成找错。**题源可切 AI / 真题**——真题模式直接抽历年原题（按年份、卷种筛），用官方参考答案，不让 AI 另编 |
| **应用文素材库** | 贯彻执行的素材按「**文种 × 结构部件**」建库（议论文那套按主题按天滚动的做法搬不过来）。文种**按真题频次排序**并标出考过几次，空格子照样列出来；配一套格式检查器，它既是出稿的闸门、又是**错例产线**——每条检查失败就产出一条成对错例，进「应用文改错」小测和今日复习 |
| **人民时评** | 每天抓《人民日报》人民时评 —— 标准的申论大作文范本，全文精读 + AI 拆解结构 |

### 社区（内江市资中县社区专职工作者）

第三条备考线，和公考并存、共用同一套引擎。卷面 100 分：单选 40 + 多选 10 + 判断 10 +
案例分析 25 + 公文写作 15 —— **主观题占 40 分**，多选与判断是行测那套引擎没有的题型。

| 模块 | 一句话 |
|---|---|
| **资中真题** | 2023 / 2025 两套原卷，整卷**模考**（总倒计时、交卷才判分）或**背题**（做一题揭晓一题）。多选是方标、单选是圆标，形状即规则；多选按「多选、少选、错选均不得分」判，揭晓时单标出**漏选**了哪个 |
| **资中专项** | 招聘公告抽成结构化字段 → 速记卡 + **程序化出题**（答案由数据保证，不让 AI 编：实测三个模型对「内部选聘招录人数」给出三个互相矛盾的数字）。每条挂来源与年份，按「真题考过 / 未经真题验证」分档 —— 8 道本地真题**全部出自公告参数**，没有一道考县情地理 |
| **考点清单** | 公告点名的范围（社工**初级** + 社区建设 + 基层治理 + 法律常识）解析成**书 → 章 → 考点**三层树：社会工作 445 个考点、社区知识 432、法律法规 96。复用讲义那套管线，只加一个 parser —— 这批资料一册一个写法（`1、`／`4社会工作…`／`考点 3——`／`第一条`），所以是一串模式按序试 |
| **入库校对** | 源卷是网传回忆版，**答案本身可能是错的**（抽查即见）。两家不同厂商的模型独立作答，有分歧才升档仲裁；判不出来一律存疑。存疑题看得见但做不到，逐条裁决后才进卷子 —— 少于两方作答绝不盖章，宁可说判不出来 |

## 几条贯穿全项目的规矩

- **AI 说的话要能核对。** 出的题过第二个模型独立核验才发给人做（单模型抽检一致率只有 89%）；「用了哪些素材」逐条回正文核对，虚报的直接丢；划重点挑的句子必须逐字来自原文；联网搜索**搜不到就说搜不到**，绝不许悄悄退回「拿训练记忆冒充搜索结果」——用户以为这是刚查的，其实是模型两年前记下的。
- **能构造的就别让 AI 算。** 资料分析、数量关系、图形推理全部程序化生成，答案由构造保证；答案落在哪个字母也由代码发牌，不指望模型听话。
- **先量再改，改完复量。** 每一轮改造都留下改前 / 改后的数字（解析与题目的对应正确率 31% → 100%；AI 题篇幅落在真题区间 11% → 62%；小题采分点「有整块材料没落上点」的题 8/11 → 1/11）。量化推翻过好几次拍脑袋的判断 —— 最近一次是「换更强的模型能治找点不全」，实测同一道题 flash 和 pro 结果同级而 pro 慢十倍，真正起作用的是**逐块扫描**这个流程结构。
- **样本少的结论不要外推。** 拿一道归纳概括量出「采分点很稳」，扩到五个题型再量：综合分析 38%、贯彻执行 53% 的句子在「标中/不标中」之间摇摆，归纳概括的 13% 才是特例。工具在 `audit_find.py --baseline`。
- **备份要有另一个故障域里的一份，而且演练过。** 本地快照和原始库在同一块盘上时，盘挂了是一起没的——这一条在后台是**黄灯常亮**，不是「可选功能未启用」。配法见 `backup.env.example`，演练用 `./restore_drill.sh`（恢复出来真起一个实例走一遍请求）。没演练过的备份不算备份。
- **「看得清、点得到」是功能的一部分，不是打磨。** 逐屏评审量过：全站用得最多的次要色只有 3.1:1（AA 要 4.5）、首页 10 个可点元素有 8 个键盘 Tab 跳不到、底部标签栏每格 77×43（触控目标要 44）。这些都不会报错，只会让人默默用不下去。改完立了尺子（`--fs-*` / `--r-*` / `--sh-*` / `--z-*`），存量写死值由一条**只减不增**的棘轮测试卡着（`tests/frontend/cssbudget.test.js`）。
- **静默失败是最贵的 bug。** 宁可当场报错，也不要悄悄写进一条空值 —— 这条在 [docs/README-full.md](docs/README-full.md) 的「踩过的坑」里有十几个真实案例。
- **同一件事只写一份。** 限时口径、题型清单、板块常量、AI 模型名……写两处迟早走散，走散了还不报错。上游一改名，主应用当天就修好了，八个定时器脚本还在原地跑旧名 —— 这类事有测试盯着（「全项目不许出现真实模型名」）。

## 技术栈

- **后端**：Python · Flask · waitress · SQLite；OCR（tesseract）、PDF（poppler / qpdf / reportlab）、Office 转换（LibreOffice）；语音转写是可插拔的一层（`mods/asr.py`，默认不接引擎，接哪家在后台选，不接也能发能听）
- **AI**：DeepSeek（OpenAI 兼容接口）为主，图片识别走智谱 GLM-4.6V，联网搜索是可插拔的一层（`mods/websearch.py`，现接 Brave，没配 key 就老实说没配）。**业务代码只说档位**（`fast` / `pro`），真实模型名只住在 `aiclient.py` 一处 —— 官方改名时只动配置，改不过来还能自己拉 `/v1/models` 探活换名
- **前端**：原生 HTML/CSS/JS 单页应用 + PWA，按职责拆成 81 个模块，服务端启动时合成 **2 个 bundle**（首屏 74 个脚本请求 → 2 个）：`core` 同步加载只装外壳与今日仪表盘，其余走 `defer` 的 `rest` 包，首屏阻塞字节 537 KB → **337 KB**；主题那支要在第一帧就位，标 `data-early` 不进包。JS 和 CSS 都挂内容指纹，改了必然重取
- **安卓**：WebView 壳 + JS 桥接；**桌面版**：Linux 用 GTK + WebKit2GTK，Windows 用 Electron（两个壳共用同一套 JS 桥）
- **部署**：systemd 用户服务 + Cloudflare 命名隧道
- **测试**：pytest 1534 条 + node:test（jsdom）585 条 + eslint

## 快速开始

```bash
# 1. 依赖
uv venv .venv && uv pip install --python .venv/bin/python3 -r requirements.txt
sudo apt install tesseract-ocr tesseract-ocr-chi-sim poppler-utils qpdf libreoffice fonts-arphic-uming

# 2. 配置：新建 config.json，至少填 AI Key 和会话密钥（不在仓库里，见完整文档）

# 3. 首次导入基础数据
.venv/bin/python3 build_db.py           # 成语词语词典
.venv/bin/python3 build_classics.py     # 古诗文
.venv/bin/python3 gen_changshi.py seed  # 常识积累（需 AI Key）

# 4. 启动（默认 8011 端口）
./run.sh
```

打开 http://localhost:8011 ，**首次进入是注册页**（没有默认账号，第一个注册者即管理员）。

> ⚠️ `app.db`（数据库）、`config.json`（密钥）、`uploads/`（用户文件）都在 `.gitignore` 里，**不在这个仓库中**，需要自己生成。
> 安装包（`dist/gongkao.apk`、`dist/gongkao-win.zip`）同理——二进制每发一版就在 git 历史里永久留一整份，
> 服务端是从文件系统发包的，包自己构建（`android/make_apk.sh`、`desktop/win/build_win.sh`）；仓库里只留几百字节的版本清单 `dist/*.json`。

## 目录结构

```
gongkao-app/
├─ app.py              # Flask 入口：鉴权、路由装配、后台任务
├─ aiclient.py         # AI 模型的唯一真源：档位（fast/pro）→ 真实模型名，零依赖（定时器脚本也 import 它）
├─ emergency.sh        # 应急自救：AI 挂了 / 后台进不去时改模型名、重启服务，只要 bash + python3
├─ mods/               # 各业务模块（真题、专项练、成文、错题本、划重点、运维、AI 工具…）
├─ static/             # 前端 SPA + PWA（js/ 下 81 个模块 + Service Worker）
├─ android/ desktop/   # 安卓 WebView 壳 / 桌面壳（desktop/ 是 Linux GTK，desktop/win/ 是 Windows Electron）
├─ tests/              # pytest + 前端 jsdom 测试
├─ docs/README-full.md # 完整文档（设计取舍、实测数据、踩过的坑）
├─ ingest_basics.py    # 讲义 PDF → 考点树（原文层与解析层分开，改规则只 --reparse）
├─ *.py                # 数据导入与定时生成脚本（爬时政、出题、生成范文…）
└─ data/               # 开源词典原料（成语/词语/古诗文）
```
