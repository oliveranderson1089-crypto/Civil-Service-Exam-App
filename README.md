# 公考助手 · Civil-Service-Exam-App

一个公务员考试备考工作台：**网页 + 安卓 APK + 电脑桌面版（Linux .deb）**，多用户、可远程访问、可离线使用（PWA）。

从「成语词语积累」起步，现在覆盖**历年真题、行测专项练、申论批改与成文、每日时政、常识与理论积累、错题本与遗忘曲线复习、笔记资料管理**，并带微信推送。

## 功能一览

### 行测

| 模块 | 一句话 |
|---|---|
| **历年真题** | 国考 2000–2026 + 四川 2007–2025 原卷，去重后 7606 道（7008 道可直接练）。智能刷 / 按题型刷（46 个题型）/ 整卷真题（**背题**：做一题就揭晓答案解析／**模考**：交卷才判分、走总倒计时）；每次作答独立留痕，错过的题到期自动排最前 |
| **⚡ 专项练** | 六大板块按题型刷，三档难度、按题型限时、薄弱题型排最前。资料分析 / 数量关系 / 图形推理**程序化出题**（答案由构造保证），其余 AI 出题 + 题库缓存。**做过的题不再重复发**——库存满 ≠ 有题做，补库按「你还剩多少没做过的」算，夜里优先补今天新学的知识点 |
| **基础知识点** | 两套机构讲义并行：**系统精讲**（章/节目录 + 例题解析）与**三色速记**（原书红蓝绿三色还原），外加**考点对照**——同一考点下先看详解、再看速记。讲义 PDF 由 `ingest_basics.py` 解析成考点树，公式和图形推理的图点开看**原书那一页**；学完就近练该考点的真题 |
| **每日巩固测试** | 按当天学的内容出一份小测，五个板块按配额组卷，背题 / 测试两种模式 |
| **常识 · 理论 · 时政** | 35 个专题 555 条常识考点、268 个理论考点、每日 3 次时政爬取 + AI 三行式解读、时政要文库、创新理论词典 316 条 |
| **成语词语 / 常考** | 高频成语 894 条（按真题考频排序、可看典故）、实词搭配、上位词、高频古诗文与提法，外加**每日古诗积累**（今日复习里当天新出的诗自动按天归档，回看背过哪些） |
| **每日新闻视频** | 抓央视网 / 川观 / B 站官方号，AI 按**公考价值**筛一遍并说清为什么值得看 |

### 申论

| 模块 | 一句话 |
|---|---|
| **真题批改** | 上传真题（PDF/Word/图片，扫描件自动 OCR）→ 自动拆题 → 逐题作答 → AI 按采分点逐点批改。两种做题模式可切：**模考**（直接写，还原考场）/ **练习**（先在材料上找点、判完再写）；采分点**预先标好存库**，同一份答案两次批改分数不飘，还能指出漏的点在材料第几句 |
| **范文推荐** | 按热门话题命制的仿真卷，材料严格按真题字数规格，每题配完整参考答案 |
| **成文** | 把积累的素材真正写成一篇大作文：每日成文 / 综合应用 / 14 个文种的应用文。**提纲归提纲、全文归全文**——每条论点在正文里落在哪一段都指得出来，正文换了说法就并排显示当「另一种写作思路」，不回头改写正文；用了哪些素材也逐条回正文核对过 |
| **小题训练** | 归纳概括 / 综合分析 / 提出对策 / 贯彻执行，拆成「只找不写」和「照着找到的点写」两步练。采分点**逐块扫全材料**标定（防止全挤在开头）+ 参考答案由采分点拼装；勾中「相关但没独立成点」的句子判**沾边**，不再误判成找错。**题源可切 AI / 真题**——真题模式直接抽历年原题（按年份、卷种筛），用官方参考答案，不让 AI 另编 |
| **应用文素材库** | 贯彻执行的素材按「**文种 × 结构部件**」建库（议论文那套按主题按天滚动的做法搬不过来）。文种**按真题频次排序**并标出考过几次，空格子照样列出来；配一套格式检查器，它既是出稿的闸门、又是**错例产线**——每条检查失败就产出一条成对错例，进「应用文改错」小测和今日复习 |
| **人民时评** | 每天抓《人民日报》人民时评 —— 标准的申论大作文范本，全文精读 + AI 拆解结构 |

## 几条贯穿全项目的规矩

- **AI 说的话要能核对。** 出的题过第二个模型独立核验才发给人做（单模型抽检一致率只有 89%）；「用了哪些素材」逐条回正文核对，虚报的直接丢；划重点挑的句子必须逐字来自原文。
- **能构造的就别让 AI 算。** 资料分析、数量关系、图形推理全部程序化生成，答案由构造保证；答案落在哪个字母也由代码发牌，不指望模型听话。
- **先量再改，改完复量。** 每一轮改造都留下改前 / 改后的数字（解析与题目的对应正确率 31% → 100%；AI 题篇幅落在真题区间 11% → 62%；小题采分点「有整块材料没落上点」的题 8/11 → 1/11）。量化推翻过好几次拍脑袋的判断 —— 最近一次是「换更强的模型能治找点不全」，实测同一道题 flash 和 pro 结果同级而 pro 慢十倍，真正起作用的是**逐块扫描**这个流程结构。
- **样本少的结论不要外推。** 拿一道归纳概括量出「采分点很稳」，扩到五个题型再量：综合分析 38%、贯彻执行 53% 的句子在「标中/不标中」之间摇摆，归纳概括的 13% 才是特例。工具在 `audit_find.py --baseline`。
- **静默失败是最贵的 bug。** 宁可当场报错，也不要悄悄写进一条空值 —— 这条在 [docs/README-full.md](docs/README-full.md) 的「踩过的坑」里有十几个真实案例。
- **同一件事只写一份。** 限时口径、题型清单、板块常量、AI 模型名……写两处迟早走散，走散了还不报错。上游一改名，主应用当天就修好了，八个定时器脚本还在原地跑旧名 —— 这类事有测试盯着（「全项目不许出现真实模型名」）。

## 技术栈

- **后端**：Python · Flask · waitress · SQLite；OCR（tesseract）、PDF（poppler / qpdf / reportlab）、Office 转换（LibreOffice）
- **AI**：DeepSeek（OpenAI 兼容接口）为主，图片识别走智谱 GLM-4.6V。**业务代码只说档位**（`fast` / `pro`），真实模型名只住在 `aiclient.py` 一处 —— 官方改名时只动配置，改不过来还能自己拉 `/v1/models` 探活换名
- **前端**：原生 HTML/CSS/JS 单页应用 + PWA，按职责拆成 63 个模块，服务端启动时合成一个 bundle（首屏脚本请求 63 → 1 个）；JS 和 CSS 都挂内容指纹，改了必然重取
- **安卓**：WebView 壳 + JS 桥接；**桌面版**：GTK + WebKit2GTK 原生壳
- **部署**：systemd 用户服务 + Cloudflare 命名隧道
- **测试**：pytest 1134 条 + node:test（jsdom）298 条 + eslint

## 快速开始

```bash
# 1. 依赖
uv venv .venv && uv pip install --python .venv/bin/python3 -r requirements.txt
sudo apt install tesseract-ocr tesseract-ocr-chi-sim poppler-utils qpdf libreoffice fonts-arphic-uming

# 2. 配置：新建 config.json，至少填 AI Key 和会话密钥（不在仓库里，见完整文档）

# 3. 首次导入基础数据
.venv/bin/python3 build_db.py           # 成语词语词典
.venv/bin/python3 build_classics.py     # 古诗文
.venv/bin/python3 gen_changshi.py seed  # 常识积累（需 AI Key）

# 4. 启动（默认 8011 端口）
./run.sh
```

打开 http://localhost:8011 ，**首次进入是注册页**（没有默认账号，第一个注册者即管理员）。

> ⚠️ `app.db`（数据库）、`config.json`（密钥）、`uploads/`（用户文件）都在 `.gitignore` 里，**不在这个仓库中**，需要自己生成。

## 目录结构

```
gongkao-app/
├─ app.py              # Flask 入口：鉴权、路由装配、后台任务
├─ aiclient.py         # AI 模型的唯一真源：档位（fast/pro）→ 真实模型名，零依赖（定时器脚本也 import 它）
├─ emergency.sh        # 应急自救：AI 挂了 / 后台进不去时改模型名、重启服务，只要 bash + python3
├─ mods/               # 各业务模块（真题、专项练、成文、错题本、划重点、运维、AI 工具…）
├─ static/             # 前端 SPA + PWA（js/ 下 56 个模块 + Service Worker）
├─ android/ desktop/   # 安卓 WebView 壳 / Linux GTK 桌面壳
├─ tests/              # pytest + 前端 jsdom 测试
├─ docs/README-full.md # 完整文档（设计取舍、实测数据、踩过的坑）
├─ ingest_basics.py    # 讲义 PDF → 考点树（原文层与解析层分开，改规则只 --reparse）
├─ *.py                # 数据导入与定时生成脚本（爬时政、出题、生成范文…）
└─ data/               # 开源词典原料（成语/词语/古诗文）
```
