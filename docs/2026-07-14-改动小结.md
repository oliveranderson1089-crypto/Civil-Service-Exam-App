### 修：桌面版截图点了没反应 — `31f4d17`

**根因是我自己的构造 bug，而且被自己吞掉了**：

```python
opts = GLib.Variant("a{sv}", {...})                       # ← 先包成 Variant
bus.call_sync(..., GLib.Variant("(sa{sv})", ("", opts)))  # ← 又塞进去
```
PyGObject 会把这个已是 Variant 的 `opts` **当 dict 迭代** → `KeyError(0)`，**D-Bus 调用根本没发出去**；而异常被 `except Exception: pass` 吞了 → 表现就是"点了没反应"。`a{sv}` 必须传**普通 dict**（只有值才是 Variant）。

- 修法：传普通 dict；portal 调用实测成功（返回 Request 句柄）
- **更重要的**：壳里加了 `_toast()`，**以后壳里出错会直接在网页上弹提示**，不再静默失败
- 验证：加载**真实壳代码** + 同款 WebKit 端到端跑通 —— 网页点截图 → 壳收到 `{"a":"shot"}` → 调起 portal `Screenshot(interactive=true)` ✓
